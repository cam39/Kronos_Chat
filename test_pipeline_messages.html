Test Pipeline Messages - Instructions

📋 Instructions de Test

ÉTAPE 1: Ouvrir 2 navigateurs différents
ÉTAPE 2: Connecter 2 utilisateurs différents
ÉTAPE 3: Aller dans le canal #kroni
TEST 1: Utilisateur A envoie un message
✅ Attendu: Message apparaît immédiatement chez A et B
✅ Attendu: Pas de chargement infini
✅ Attendu: Kroni répond après le message
TEST 2: Recharger la page
✅ Attendu: Message utilisateur reste présent
✅ Attendu: Ordre chronologique respecté
TEST 3: Redémarrer le serveur
✅ Attendu: Message reste en base de données
✅ Attendu: Message apparaît au rechargement

🔍 Debug Console

Ouvrir la console F12 et vérifier:
- [DEBUG] handle_send_message called
- [DEBUG] Creating message
- [DEBUG] Message saved to DB
- [DEBUG] Emitting new_message
- [DEBUG] confirmOptimisticMessage called
- [DEBUG] Updating message in state
- [DEBUG] Updating DOM element

🐛 Problèmes à Surveiller

❌ Message reste en chargement infini
❌ Message utilisateur n'apparaît pas chez l'autre
❌ Message disparaît après rechargement
❌ Ordre incorrect (réponse avant question)
❌ Erreur "processEmbeds is not a function"
